# pairwise-status-stack

Boss 身上叠了五层灼烧，驱散后还剩两层，玩家死了复活还带着减速，切场景后 buff 图标全乱：层数叠加用独立实例，刷新时间只更新最新一层，旧层到期后整组消失；持续伤害按层数乘算，但每层各自 tick，同一帧结算五次；驱散按 buff ID 删，没按优先级和层数扣，五层只掉三层；属性修改是快照式，叠层后攻击力不随层数变化；免疫和抗性只挡新 buff，已有层数不移除；死亡时只清玩家自身 buff，Boss 施加的减速留在尸体上；切场景时 buff 容器重建但图标索引没重排，图标错位；网络复制只发层数不发剩余时间，客户端倒计时和服务器差几秒；周期伤害用帧计数，掉帧时少跳一次；buff 叠加上限按数组长度，超过上限后新 buff 覆盖旧 buff；驱散免疫只判断类型不判断来源，Boss 的不可驱散 buff 被玩家驱散；复活后 buff 快照从死亡前恢复，连无敌帧一起带回来；多线程结算和驱散同时改层数，层数变成负数。gameplay/status_stack.py 是核心，tests/test_status_stack.py 15个红。要修的是：层数刷新；单次结算；驱散优先级；动态属性；抗性清理；死亡清理；图标重排；剩余时间复制；tick 补偿；上限策略；来源过滤；复活快照；并发锁。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
